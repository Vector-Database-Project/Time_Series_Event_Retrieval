Overview

This project studies time-series event retrieval using a controlled ECG benchmark derived from the MIT-BIH Arrhythmia Database. The central question is whether retrieval quality is shaped more by the chosen signal representation or by the embedding method applied downstream.

To make that comparison clean, the final benchmark uses a leakage-aware record-level split, a coarse three-class label space, fixed beat-centered windows, and a common nearest-neighbor retrieval evaluator applied uniformly to all runs. The report therefore focuses on one reproducible experimental setting rather than a loose collection of ad hoc trials.

Problem framing

The project is not framed as a single-model optimization task. Instead, it treats retrieval as a pipeline problem with three linked stages: preprocessing, embedding, and evaluation. The preprocessing stage defines what each event looks like. The embedding stage determines how events are represented numerically. The evaluator then tests whether those embeddings recover the correct class neighborhoods under nearest-neighbor retrieval.

Final report focus

  • define the final leakage-aware ECG benchmark and its preprocessing policy
  • describe the compared embedding families and representation choices
  • report the retrieval results for the full 18-run matrix
  • identify the benchmark-specific conclusion supported by the observed metrics
