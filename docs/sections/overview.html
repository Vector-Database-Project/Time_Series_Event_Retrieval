Overview

Time-series event retrieval aims to find past signal events that are similar to a query event. In this project, fixed event windows are converted into vector representations so they can be compared through nearest-neighbor retrieval. This page documents the current ECG implementation of the broader time-series event retrieval project. The original project direction is cross-domain, but the present deployed content reflects what has actually been built and evaluated so far.

The current implemented scope includes ECG preprocessing, a saved train/test split, a single-event walkthrough, a Gaussian Random Projection embedding baseline, and a common retrieval evaluation path with saved metrics and confusion-matrix artifacts.

  • Raw MIT-BIH records are converted into fixed beat-centered event windows.
  • Aligned time-domain and frequency-domain views are saved to disk.
  • A stratified random train/test split is materialized at processed/v1tts.
  • Gaussian random projection has been run for time and frequency inputs at 64 and 128 dimensions.
  • Evaluation currently reports Accuracy@K, Recall@K, F1@K, and confusion matrices.
