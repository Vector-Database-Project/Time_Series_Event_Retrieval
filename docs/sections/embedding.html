Embedding and Evaluation Pipeline

The embedding stage is downstream of preprocessing. It consumes the already-saved test and train splits, loads aligned shards, flattens each sample into one row of X, and fits the selected method on the training split only.

Implemented baseline

The first completed embedding baseline is Gaussian Random Projection. For the current pass, it has been run on both time-domain and frequency-domain inputs at 64 and 128 projected dimensions.

Current execution flow

  1. load the full train split for the selected representation
  2. load the full test split for the same representation
  3. fit the embedding method on train only
  4. transform train and test into embeddings
  5. save embeddings, labels and projection artifacts
  6. evaluate retrieval using the saved embedding artifacts

Current evaluation behavior

  • use train embeddings as the reference pool
  • use test embeddings as queries
  • retrieve top-K nearest train embeddings for each test query
  • assign the predicted label by majority vote over retrieved labels
  • report Accuracy@K, Recall@K, F1@K, and confusion matrices
